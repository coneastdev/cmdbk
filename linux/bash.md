# bash

linux bash console commands and common utilities

## navigation

```
cd
```

Used to change your current working directory to the give location.

Remember to use tab for auto complete.

```
cd ..
```

Used to change your working directory to the parent of the current directory.

```
mkdir
```

Lets you make a new directory at the specified path/name.

Some commands will let you use "--mkdir" when specifying a path to create the directory if it does not exist.

```
grep
```

Outputs the contents of a given file.

```
nano
```

A really basic CLI editor that comes with most distros. It is vital if your GUI is not working.
